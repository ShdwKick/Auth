# Проверки

Обычные скрипты на Node, без тестового фреймворка — в духе остального проекта
(зависимостей нет, ставить нечего). Каждый поднимает всё нужное сам, на временной базе
в `test/.work*`, и заканчивается либо «прошли», либо ненулевым кодом возврата.

На Node 24 — просто `node`. На Node 22 добавьте `--experimental-sqlite`.

```bash
node test/legacy-passwords.mjs   # перенос паролей из «Моих финансов» (сети не требует)
node test/flow.mjs               # сам auth-сервис; занимает порт 8788
node test/e2e.mjs                # auth + Финансы вместе; занимает 8787 и 8788
```

Что покрыто:

| Скрипт | Проверяет |
|---|---|
| `legacy-passwords.mjs` | старый пароль из Finance подходит после импорта; хэш прозрачно апгрейдится в `scrypt-v1`; повторный импорт не плодит дублей |
| `flow.mjs` | authorization code + PKCE, отказ на чужом `code_verifier` и `redirect_uri`, одноразовость кода, SSO по куке, ротация refresh, распознавание кражи токена, отзыв из кабинета, CORS, лимит на перебор паролей, локальная проверка подписи клиентской библиотекой |
| `e2e.mjs` | вход старым паролем Finance, ленивый переезд данных на `user_id` с сохранением старой строки, чтение/запись состояния, протухание и обновление access-токена, **сохранение сессий после рестарта auth**, отказ на токене с чужой подписью |

`e2e.mjs` ожидает, что репозиторий «Моих финансов» лежит рядом — в `../Финансы`;
другой путь задаётся переменной `FINANCE_DIR`.
